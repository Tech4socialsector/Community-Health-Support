# v1.0.0 — Cancer programme, programme modules and Outreach Clinic

## Summary
The app becomes one app for several programmes: each programme (MCH, Palliative Care, Mental Health, NCD, Cancer) can be switched on or off per organisation. A full Cancer screening programme was added, with Outreach Clinics, place codes and Cancer roles, plus a Programme setup page and a common Overview.

Covers 11 commits from 15 October – 26 November 2026.

## Feature highlights
- Cancer screening: Main Screening Form, Clinical Evaluation and clinic worklist.
- Switch programmes, forms and even single questions on or off per organisation (Programme setup).
- Outreach Clinic with an automatic 7-digit ID (District 2 + Block 2 + Panchayat 3 digits).
- District → Block → Panchayat → Village place selection that fills itself.

## Module-wise changes

### Cancer
**Introduced:**
- Main Screening Form (oral, breast and cervical screening) and Clinical Evaluation, with their masters.
- Only referred and finished screenings move to Clinical Evaluation; clinic worklist; "Finish evaluation".
- Outreach Clinic: name, Active tick, dates and place; ID built from the place codes, one clinic per panchayat.
- Site master for oral screening sites.
- Roles: Cancer Program Coordinator, Cancer Outreach Clinic Coordinator, Cancer Social Worker, Cancer Doctor, Cancer Nurse (no permissions; set per site).

**Modified:**
- Household Profile: Outreach Clinic ID first; the clinic fills District, Block, Panchayat and Village.
- Cancer fields on Household Profile and Family Members show only while Cancer is on, and only to Cancer staff.

**Problem addressed:** Cancer screening ran in a separate app with no link to households and outreach camps.
**Roles affected:** Cancer Worker, Program Coordinator, the new Cancer roles.
**Administrator action:** give the new Cancer roles their permissions; add Sites; create Outreach Clinics.

### Programmes & settings
**Introduced:**
- Programme modules with on/off switches and form ticks in App Setting.
- Programme setup page: choose programmes, forms and questions per organisation.
- Common Overview built from App Setting.

**Modified:**
- One-click save on forms.

**Roles affected:** System Manager, Program Coordinator.
**Administrator action:** open Programme setup and switch on the programmes this site uses.

### Masters (places)
**Introduced:**
- Taluk Block master; codes on District (2 digits), Block (2) and Panchayat (3).
- Picking a lower place fills the ones above; lists are filtered by the level above; "+ Create" pre-filled.

**Modified:**
- District is named by the user instead of an automatic number.
- Household Profile and Family Members: District → Block → Panchayat → Village; Subcenter hidden.

**Administrator action:** give existing Districts, Blocks and Panchayats their codes.

### Fixes
- App Module Settings for every programme exported as fixtures; cancer masters seeded.
- Cancer survey questions hidden when Cancer is off.

## Technical changes
- New modules: Cancer, Palliative Care, NCD Care (programme doctypes moved from Common).
- New doctypes: Main Screening Form, Clinical Evaluation and cancer masters; Outreach Clinic, Outreach Clinic Village; Taluk Block; Site.
- New code: `chw/programmes.py`, `chw/field_settings.py`, `chw/places.py`, `chw/overview.py`, `chw/cancer/` (eligibility, outreach, worklist, queries).
- New app pages: Programme setup, Clinical worklist.
- Fixtures: App Module Setting for every programme; Role (5 Cancer roles).
- 12 database patches, including moving programme doctypes to their modules, renaming Districts to their names, seeding cancer masters and storing the new App Setting ticks.

## Breaking changes
- District records are renamed from numbers to their names; links to them are updated by the patch.
- Programme forms moved to new modules (Cancer, Palliative Care, NCD Care); custom scripts that refer to the old module names need updating.
- With Cancer and Outreach Clinic on, Cancer Workers must choose an Outreach Clinic for new households.

## Deployment instructions
```
cd <bench>
bench --site <site> backup
cd apps/chw && git fetch && git checkout v1.0.0 && cd ../..
bench --site <site> migrate
bench build --app chw
bench restart
```
Migrate runs the database patches of this release. Take the backup first: this release renames Districts and moves doctypes between modules.

## Upgrade considerations
- After deploying, users get the new version the next time they open or reload the app. If a new form's card does not open, clear the site data in the browser once.
- Programmes are off on a new site; switch them on in Programme setup.
- Organisation-specific IDs (Street ID, 16-digit household IDs) are set up per site with Customize Form and Server Scripts, not in this release.
