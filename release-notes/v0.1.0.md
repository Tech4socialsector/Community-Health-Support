# v0.1.0 — Core CHW forms and dashboards

## Summary
First version of the Community Health Worker app: households and family members, mother-and-child (MCH) forms, Palliative Care, NCD and Mental Health forms, dashboards and a Work Order list, available in Desk and in the CHW app, which can be installed on phones.

Covers 38 commits from 28 August – 8 October 2026.

## Feature highlights
- Register households and family members, then follow mothers and children through pregnancy, delivery and the first year.
- Palliative Care initial assessment and follow-up forms.
- Dashboards with number cards, and a Work Order list of due visits.
- The CHW app can be installed from the browser (PWA).

## Module-wise changes

### Household & Family
**Introduced:**
- Household Profile and Family Members forms, with relationship to head of the family, village, state and district.
- Connections and roles between Family Members, Pregnancy Registration, ANC and Birth Registration.

**Modified:**
- Age and delivery status on Family Members; field-level changes from review.

**Roles affected:** CHW Health Worker, Program Coordinator.

### Mother and Child (MCH)
**Introduced:**
- Pregnancy Registration (with BMI calculation and Pregnancy High Risk master), ANC Follow-up with doctor and nurse notes, Birth Registration.
- PNC, Postpartum, Preconception and Child 6 weeks – 1 year registration and follow-up forms.
- Visit interval masters for ANC, PNC, Postpartum and Child 6w–1y; PNC visits set to monthly.

**Modified:**
- Child 6w–1y visit schedule rebuilt on PNC's milestone pattern.
- From / To dates on follow-up forms; ANC and PNC review changes.

**Problem addressed:** CHWs had no structured way to record and follow mothers and children.
**Roles affected:** CHW Health Worker, MCH Worker.

### Palliative Care
**Introduced:**
- Palliative Care Initial Assessment and Follow-up forms: symptoms, pain, pressure sores, body systems, primary caregiver, consultation, medicines.

**Roles affected:** Palliative Care Worker.

### NCD and Mental Health
**Introduced:**
- NCD and Mental Health forms with their masters (NCD Disease, NCD Complications, Mental Health Symptom).

### Dashboards & Work Orders
**Introduced:**
- Number cards, CHW Dashboard, Visit Dashboard and five more dashboards.
- Work Order list of due visits, with drill-down and Next / Previous pagination.

**Roles affected:** Program Coordinator, CHW Health Worker.

### CHW app
**Introduced:**
- CHW app (Vue) with Home, Overview, Work Orders, lists and forms.
- Installable app (PWA); Frappe's native icon picker for module icons.

## Technical changes
- New modules: CHW Master (masters, App Setting, App Module Setting, dashboard cards, visit interval masters) and Common (household, family and programme forms).
- Desk pages: CHW Dashboard, CHW Visit Dashboard, CHW Work Order List.
- Fixtures: Number Card, Workspace, Workspace Sidebar, Desktop Icon, App Module Setting.
- Service worker renderer for the CHW app (`chw/website/sw_renderer.py`).
- 17 database patches (masters, app modules, dashboard cards, visit intervals, label and icon renames).

## Breaking changes
None. First release.

## Deployment instructions
```
cd <bench>
bench --site <site> backup
cd apps/chw && git fetch && git checkout v0.1.0 && cd ../..
bench --site <site> migrate
bench build --app chw
bench restart
```
Migrate runs the database patches of this release.

## Upgrade considerations
- First installation: `bench --site <site> install-app chw` before migrate.
- Installing the CHW app on a phone requires the site to be served over HTTPS.
