# v0.2.0 — Vue app, offline mode and chw-lch merge

## Summary
The CHW app now does everything Desk does for field staff, works without internet and syncs later, and can be used in other languages. Place masters and one visit-schedule master were added, and the chw-lch branch was merged into develop.

Covers 20 commits from 9 – 15 October 2026 · pull request #1.

## Feature highlights
- Offline data entry with an Outbox that syncs when the phone is back online.
- Language switcher with automatic translation.
- Gram Panchayat, Sub Centre and Occupation masters.
- Work Orders renamed to My Work, driven by one Visit Schedule master.

## Module-wise changes

### CHW app
**Introduced:**
- Desk-style list filters; "Create new" straight from link fields.
- Phone number validation across the app.
- Required fields checked before saving, online and offline.
- Language switcher with Google auto-translate.

**Modified:**
- Brought to Desk parity for field staff; birth registration and permission fixes; save fixes.
- Location fields cleaned up; read-only links styled clearly.

**Problem addressed:** field staff needed Desk for some tasks and could not work in English only.
**Roles affected:** all field staff.

### Offline mode
**Introduced:**
- Offline data entry with an Outbox page; records sync when back online and get their IDs at sync.
- App updates activate automatically, so offline works right after a deploy.

**Modified:**
- "Offline IDs per Form" setting removed; IDs are given at sync.

**Fixed:**
- Offline reload on first visit and the /chw tile.
- Permission checks on offline sync retries and link searches.

**Problem addressed:** staff in areas without network could not record visits.
**Roles affected:** all field staff.

### Masters & scheduling
**Introduced:**
- Gram Panchayat, Sub Centre and Occupation masters.
- Visit Schedule master replacing the separate interval masters; interval schedule setup.

**Modified:**
- Work Orders renamed to **My Work**.
- Charity Assessment (LCH criteria) moved from Household Profile to Family Members.

### Settings
**Introduced:**
- Case Register mandatory-field override setting.

**Administrator action:** review the Visit Schedule master after upgrading.

## Development process
- chw-lch branch merged into develop (#1); merge conflicts resolved.

## Technical changes
- New doctypes: CHW Offline Sync, CHW Reserved ID, Gram Panchayat, Sub Centre, Occupation, Visit Schedule Master / Program / Row.
- New modules: `chw/offline.py` (offline download and sync), `chw/permissions.py`, `chw/translation_tool.py`, `chw/chw_master/visit_schedule.py`.
- New app pages: Outbox, Record View.
- hooks.py: offline sync, permission and translation hooks.
- 3 database patches: CHW roles, PNC visit interval rows, Visit Schedule master seed.

## Breaking changes
- Work Orders is now **My Work**; bookmarks to the old page should be updated.

## Deployment instructions
```
cd <bench>
bench --site <site> backup
cd apps/chw && git fetch && git checkout v0.2.0 && cd ../..
bench --site <site> migrate
bench build --app chw
bench restart
```
Migrate runs the database patches of this release.

## Upgrade considerations
- Offline mode needs the site served over HTTPS.
- After deploying, users get the new version the next time they open or reload the app.
- Records saved offline before the upgrade sync normally afterwards.
